## 一、项目是什么

**定位**：连接身体状态与内心状态的 AI 生命陪伴体。
- 充氧宝硬件负责给身体补氧，氧氧宝负责帮用户"发现自己的氧"。
- 通过 情绪识别 + AI 陪伴 + 场景化健康方案 + 成长体系，帮助用户管理情绪能量、建立更好生活方式。
- **非医疗诊断**，定位为"情绪能量管理与自我成长陪伴"。

**面向**：青年用户情绪能量管理；场景覆盖 高原 / 脑疲劳 / 运动恢复 / 银发陪伴 四大场景（充氧宝产品入口）。

## 四、核心数据流（打卡闭环）

```
用户打卡(文字/拍照/状态) → emotionEngine/faceApi 分析情绪
→ stateEngine 生成氧气状态(能量/情绪/关键词/状态/建议+五项能量指数)
→ checkinService 附加食谱/场景匹配 → addRecord 存 history
→ 报告页展示 → 成长值/成就触发 → IP 成长
```

## 九、2026-08-29 性能优化专项记录（微信官方指南 12 项核查）
