## 五、产品设计决策记录

### 1. IP互动实现方案
- **决策**：PNG静态切图 + CSS微动效（不使用3D建模/骨骼动画）
- **原因**：MVP阶段性价比最高，小程序包体积小，低端机不卡顿
- **实现**：呼吸浮动（keyframes float）+ 点击弹跳（scale+rotate）+ 气泡文案

### 2. 打卡入口设计
- **决策**：去"打卡"化，绑定IP点击唤起轻量手账抽屉
- **原因**：避免"又一个需要打卡的软件"，降低使用门槛，增加陪伴感
- **实现**：点击IP/状态条 → 底部抽屉升起 → 五档氧状态轻选 + 可选拍照 + 手账文字 → 确认存好今天的氧气

### 3. 双氧模型
- **身体氧 Body Oxygen**：硬件充氧数据 + 活动 + 睡眠 + 生理数据
- **心灵氧 Mind Oxygen**：AI情绪选择 + 照片 + 对话 + 行为
- **冲突处理**：发现差异而非覆盖，如"你的身体氧气状态不错，但我感觉你的心里好像有点缺氧"

### 4. 分享卡方案
- **决策**：静态海报图片（6种人格对应6张海报）
- **原因**：动态合成代码复杂易失败，静态图100%保证视觉质量，适合9.10展示
- **实现**：根据人格ID（1-6）展示对应静态海报，wx.saveImageToPhotosAlbum保存
