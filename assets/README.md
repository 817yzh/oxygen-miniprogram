# 氧氧宝 · 设计素材与留痕（assets/）

本目录收纳氧氧宝（充氧宝情绪健康小程序）开发过程中的**设计图稿、IP形象与UI素材**，作为 OPC 大赛"可追溯证据链"的工作留痕。

## 目录结构
- **design-pack/** — 各阶段设计包（IP形象定稿 SVG/PNG、核心页面总览、穿搭/气质原型 HTML、小狐狸呼吸原型等）
- **ip-ui/** — IP形象与UI素材（IP形象、IP扩展运动、UI设计图稿、氧系MBTI人格图、小视频、数据库、核心代码收录、说明书）

## 说明
- 素材由项目团队与 AI 协作产出（ChatGPT/Gemini 图像 + 人工设计调校）
- 视频类大文件与第三方品牌原始资料（Work Air 产品技术文档）不纳入仓库，仅保留在本地 `12_充氧宝业务` 文件夹
- 完整工作过程记录见 `docs/氧氧宝_人机协作工作记录_OPC核查版.md`
