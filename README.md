# 氧氧宝 · 氧系MBTI AI情绪陪伴小程序

> 连接身体与内心的氧气伙伴 —— 基于多模态 AI 的情绪健康监测与调节系统

## 📖 项目简介

**氧氧宝**是面向高原、运动、脑疲劳、银发四大场景的情绪健康 AI 监测及调节工具。
以"氧气"为隐喻，通过情绪感知 + AI 陪伴 + 补氧方案推荐，帮助用户管理情绪能量、实现自我成长。

- **签约企业**：西藏充氧宝科技有限公司
- **技术亮点**：多模态情绪识别（拍照/文字）· 豆包大模型 AI 陪伴 · MBTI 氧系人格 · 场景模拟
- **出品**：OPC 创业大赛 · 进化营产业场景实践

## 📁 目录结构

```
oxygen-miniprogram/
├── miniprogram/     # 微信小程序前端（WXML/WXSS/JS 原生开发）
│   ├── pages/       # 24 个页面（首页/聊天/人格测试/打卡/场景模拟…）
│   ├── components/  # 自定义组件（IP形象/图表/推荐卡…）
│   ├── mock/        # 前端规则引擎数据（人格/成就/偏好/食谱…）
│   ├── utils/       # 工具（情绪引擎/聊天引擎/分享海报/人脸识别…）
│   ├── images/      # 本地图片资源
│   └── app.js       # 小程序入口
└── backend/         # Node.js 后端服务（零依赖，原生 http）
    ├── src/         # 路由 / 服务 / 数据层
    │   ├── routes/      # REST API（聊天/情绪/打卡/人格/成长…）
    │   └── services/    # 豆包大模型接入 / 情绪分析 / 聊天服务
    ├── scripts/     # 运维脚本
    ├── tests/       # 测试
    └── data/        # JSON 数据存储（运行时生成）
```

## ✨ 核心功能

- 🐦 **IP 形象氧氧**：品牌狐狸化身，贯穿全流程陪伴
- 🎭 **氧系 MBTI 人格测试**：拍照识别情绪 + 测试生成专属氧系人格
- 🤖 **AI 陪伴聊天**：豆包大模型驱动的情绪陪伴对话（失败自动回退规则引擎）
- 🧪 **场景模拟器**：高原/军疲劳/运动/银发场景氧需求模拟
- 💚 **每日打卡**：记录情绪与状态，生成氧气手账
- 🛒 **充氧宝产品中心**：场景化补氧方案与产品选型

## 🚀 运行方式

### 小程序前端
1. 微信开发者工具导入 `miniprogram/`
2. appid 使用 `project.config.json` 中配置的
3. 本地编译预览

### 后端服务
```bash
cd backend
cp .env.example .env   # 填入 ARK_API_KEY（火山方舟/豆包密钥）
node src/server.js     # 默认端口 3000，可用 PORT 覆盖
```

## 🔑 环境变量

| 变量 | 说明 |
| --- | --- |
| `ARK_API_KEY` | 火山方舟（豆包大模型）API 密钥，未配置时自动回退规则引擎 |
| `ARK_MODEL` | 模型名，默认 `doubao-seed-2-0-lite-260428` |
| `PORT` | 后端端口，默认 3000 |

## 📌 技术栈

- **前端**：微信小程序（原生 WXML/WXSS/JS）
- **后端**：Node.js（零第三方依赖，原生 http + JSON 文件存储）
- **AI**：豆包大模型（火山方舟）Chat Completions + Responses 多模态
- **图片**：GitHub Pages + jsDelivr CDN
