## 1. 背景与目标

- **优化前：** 主包约 **1.5MB**（其中图片 0.99MB），算上 tests/docs 等开发文件的上传包约 **1.67MB**，已超过指南建议的 **1.5M 阈值**，逼近 2M 上限，加载速度受影响。
- **目标：** 逐项对照官方 12 项检查点，整改超限项，将主包降至 1.5M 以下，并为后续功能预留体积空间。
- **约束（人机共识）：** 不重构业务逻辑、不破坏现有页面/流程、可恢复（归档而非删除）。

## 3. 具体改动明细

### 3.1 分包（subPackage）—— 主包 1.5MB → 0.50MB

在 `app.json` 中新增 4 个分包，**页面文件原地不动**、分包 root 直接指向现有目录，保证所有相对路径零改动、零破坏：

| 分包 root | 页面 | 说明 |
|---|---|---|
| `pages/mbti` | 测评流 4 页 | 氧系人格测试（低频） |
| `pages/share` | 分享页 1 页 | 人格海报分享（含 848K 海报） |
| `pages/scene-simulator` | 场景模拟器 1 页 | 含 100K 场景缩略图 |
| `pages/scene-detail` | 场景详情 1 页 | 低频详情页 |

主包保留：登录页、4 个 tabBar 页（陪伴/探索/充氧宝/我的）及热路径页面（聊天、呼吸、打卡等 17 页）+ 全部 mock/utils/components。

### 3.2 大图移出主包（图片物理搬迁 + 改引用）

- `images/posters/`（6 张，848K）→ `pages/share/posters/`，同步更新分享页 2 处引用
- `images/scene-thumbs/`（4 张，100K）→ `pages/scene-simulator/scene-thumbs/`，同步更新场景模拟器 4 处引用

> 图片仅被对应子包页面引用，移入子包后**既缩小主包、又随子包懒加载**。

### 3.3 无依赖文件归档（`_archive/`）

依据指南第 11 项「无依赖文件」清理，采用**归档可恢复**策略：

- **5 个未使用组件**：energy-index / oxygen-change-chart / oxygen-map / oxygen-suggestion / scene-board → `_archive/components_unused/`
- **4 个未使用工具**：llm-service / oxygenService / placeholderImages / sharePoster → `_archive/utils_unused/`
- **1 个备份文件**：`profile.wxss.bak_20260827` → `_archive/backups/`
- **2 个未使用 mock**：oxygen-change-db / oxygen-suggestion-db（被 tests 引用）→ 留原位，通过 `packOptions.ignore` 排除出包
- **归档说明**：`_archive/README.md` 记录恢复方法

### 3.4 配置修复（`project.config.json`）

`packOptions.ignore` 新增 13 条排除规则：tests/、docs/、_archive/、*.md、*.py、*.docx、_verify.js、空图片目录等，确保开发文档/工具不进入代码包。

同时清理 5 个空目录（images/ip-actions、mbti、persona、scene、video）。

### 3.5 顺带修复（优化过程中发现）

- **导航 bug**：`pages/chat-stat/chat-stat.js` 用 `wx.switchTab` 跳转 chat（非 tabBar 页），改为 `wx.navigateTo`。全仓排查确认其余 switchTab 目标均为合法 tabBar 页。
- **首页视频兜底（P0）**：`pages/home/home.js` 补齐视频逻辑契约 —— `initIntroVideo`（URL 读配置、默认隐藏）、`onIntroVideoError`（加载失败隐藏不黑屏）、`closeIntroVideo`（关闭记住不再自动播），并补上 `home.wxml` 视频位与样式。修复既有回归守卫测试失败。
