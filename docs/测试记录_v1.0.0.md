## 二、隔离测试数据说明（关键）
- **问题：** 直接在共享数据库跑会受 `test_user_001` 历史残留数据影响（"初始为0""首次打卡 isNew"等断言会误判）
- **隔离方法：** 复制后端源码到独立临时目录 `oxygen-backend-test`（排除 data/、.env、node_modules），在该目录首次生成全新空数据库跑测试
- **结果：** 所有"初始状态/首次打卡"断言基于**全新数据**验证通过，无任何残留数据污染
- **正式数据未受影响：** 运行中后端（3001）的正式 data/ 原封不动
