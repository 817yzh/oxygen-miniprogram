三、主线任务：情绪健康AI监测及调节系统
这是任务书正式签约的场景，也是杨子涵个人在OPC进化营中的核心交付责任。
3.1 问题背景
充氧宝当前的内容与AI工具体系（博主筛选、视频剪辑）只覆盖&quot;生理补氧&quot;维度，四大场景下都伴生着未被满足的情绪问题：
场景
核心情绪问题
高原场景
游客因高反产生焦虑、紧张情绪，影响旅行体验
脑疲劳场景
加班/备考人群长期高压，伴随注意力下降、烦躁、情绪低落
运动场景
运动后疲劳影响恢复心态，长期训练可能导致倦怠
银发场景
中老年人因身体不适产生孤独、抑郁倾向；子女关注父母情绪健康
另外存在四点系统性缺口：情绪数据未被系统采集；内容缺乏情绪洞察；情绪状态下缺乏调节内容触达；品牌尚未建立&quot;情绪陪伴型补氧&quot;的差异化心智。
3.2 项目目标
在4-6周内，用轻量级AI能力构建&quot;情绪感知→洞察输出→内容推荐&quot;的初步验证能力，最终交付一个可演示的小程序原型，推动充氧宝从&quot;生理补氧工具&quot;升级为&quot;生理补氧+情绪陪伴&quot;双轮品牌心智。
3.3 产品设计
功能模块
说明
情绪识别
用户拍照/录音/文字输入 → AI识别情绪状态（焦虑/烦躁/倦怠/孤独等）
趣味解读
结合星座、命理、运势生成个性化&quot;电子算命&quot;式解读，用于引流
调节建议
根据情绪状态推送针对性内容（视频/文章/话术）
产品引导
调节建议中自然融入充氧宝产品推荐，形成引流闭环
用户流程：打开小程序 → 拍照/录音/文字输入 → AI分析情绪 → 输出情绪标签+置信度 → 趣味解读 → 调节建议 → 产品推荐。
技术路径：文本情绪识别用 DeepSeek/Claude API + Prompt工程；语音/面部情绪识别调用现成开源模型或API（面部识别为备选，视进度决定是否纳入MVP）。核心原则：不训练模型，调用现成能力快速验证。
