# 氧氧宝 V1.0 视觉与交互改造稿（GPT 方案）
来源：涵姐给 GPT 源码+材料包+截图后，GPT 输出的 V1.0 升级方案（2026-08-23）
定位：比赛最终展示版 / 可持续迭代版

## 格言
> "像一栋已经盖好的房子：地基有了、房间有了、装修完成一半。缺的是灯光、动线和家的感觉。不是继续加功能，而是让评委30秒内产生感觉：这个氧氧，好像真的在陪一个人生活。"

## 核心目标
不增加大量功能，让已有功能形成完整体验闭环。
- 让用户**第一次打开就理解**，**每天打开都有理由**
- 从"健康管理小程序" → "懂我的氧气伙伴"

## 关系链
认识我 → 理解我 → 陪伴我 → 帮助我变好 → 推荐适合我的方案

## 一、整体体验路径重构

### 新用户路径
1. **氧氧唤醒页**（首次进入，不是直接首页）：氧氧从气泡出现 + 文案"让我用30秒认识你" + 【开启我的氧气人格】
2. **氧系人格测试**：保持现有MBTI流程，但强化仪式感
   - 完成改："你的氧气人格已生成 🌿深氧探索者" + 敏感度82%/恢复力76%/活力68%
   - 生成"氧气身份证"可分享

## 二、首页 V1.0（=每日氧气入口）
结构：氧氧问候(第28天) → 今日氧气状态(氧气指数82+一句话) → 今日行动(3分钟恢复训练+开始+奖励) → 氧氧建议(音疗/呼吸/补水) → 成长记录(氧气树生长)

**氧气地图改造**：四指标平铺 → **氧气生命球**（中心今日氧气值82 + 外围四维标签：情绪/恢复/活力/含氧感）——降低数据压力、增加生命感

**今日建议改造**：像推荐 → 氧氧主动说（"我注意到你最近晚上恢复时间变短，今晚试试睡前5分钟音疗"）增强AI感

## 三、氧氧聊天页（=陪伴关系，非聊天机器人）
- 顶部：氧氧助手 → **"氧氧陪伴中 💚 陪伴第28天"**
- 加**氧氧记忆卡**（记得：你喜欢安静/学习压力/关注高原）——AI差异化核心
- 快捷按钮：功能入口 → **情绪入口**（今天怎么样？开心/一般/有点累/压力大）

## 四、氧气探索页（=我的氧气宇宙）
"氧气探索" → **"我的氧气宇宙"**：顶部氧气星球(人格+Lv3) + 四探索入口(🧬人格探索/🧪测试/🎧音疗/🫂同类连接)

## 五、我的页面（=氧气档案馆）
"太像普通APP" → **氧气档案馆**：个人身份(涵涵·深氧探索者·Lv3·28天) + 我的氧气报告/成长/记录/成就/健康声明

## 六、充氧宝页面（=方案中心，非商城）
"买设备" → **"根据你的氧气人格推荐专属方案"**：学习恢复方案(充氧宝设备+呼吸训练+音疗陪伴) + 查看方案

## 七、视觉升级
保留：薄荷绿/奶油白/玻璃卡片/氧氧IP
增加：①氧气粒子(气泡漂浮/呼吸光晕) ②IP状态变化(状态好开心漂浮/状态低安静陪伴/庆祝动作) ③成长反馈(完成→"氧氧收到了你的照顾🌱成长值+10 氧气树成长20%")

## 八、导航栏
保持五栏不变（首页/氧氧/氧气探索/充氧宝/我的），升级图标为3D软萌IP风：
首页=氧气泡 / 氧氧=氧氧头像 / 探索=实验瓶+气泡 / 充氧宝=设备 / 我的=成长树

## 九、比赛 Demo 展示路线（90秒黄金路径）
- 0-15s：打开→氧氧"让我认识你的氧气频率"
