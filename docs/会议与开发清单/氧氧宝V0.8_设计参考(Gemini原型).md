## 三、五大主页面（参考原型结构）

### 1. 首页 Home
- 欢迎区：渐变卡（薄荷绿→奶油白→暖杏）+ 头像 + IP气泡（"你的氧气状态：我都看在眼里呢~"）
- **今日氧气地图**：中心环状仪表盘（综合状态分数 86/良好）+ 4指标格（情绪能量/视觉疲劳度/脑力加载/嗅觉状态）
- **今日建议**：文案 + 绿色按钮"查看方案→"
- **氧气变化（与昨日比）**：3格↑↓（疲劳↓20%/专注↑15%/活力↑18%）+ 查看完整报告
- **快捷入口宫格**：发现你的氧气人格 / 和氧氧聊聊（2格）

### 2. 氧氧（聊天）Chat
- 顶部"氧氧陪伴中"状态标签
- IP形象卡 + 问候"今天想和氧氧聊点什么呢？"
- **快捷入口3格**：[我的状态][追踪氧方案][了解充氧宝]
- **氧氧记忆卡**：记住的好（26岁|经常加班|父母50+|高原1-2次）+ 管理偏好
- 气泡对话 + 快捷话术条 + 输入框（圆形发送按钮）

### 3. 氧气探索 Oxygen Lab
- **发现你的氧气人格**（基于MBTI）：人格头像行（INTP/ENFP/ESTJ/INFJ）
- **含氧感自测**：10道题
- **场景模拟器**：预测氧需求
- **我的氧气码**：三角雷达（脑力负荷72，中心分66/中等风阻）+ 重新检测

### 4. 充氧宝（产品）Product
- 产品主视觉（设备渲染）
- **4规格格**：320g/3.5h/5-6L/0耗材
- **图标功能行**：为什么需要充氧/产品型号/技术原理/认证环节
- **四大场景方案**：高屏守护💻/考力增料📚/运动恢复🏃/银发守护👵（2×2宫格）
- FAQ折叠

### 5. 我的（个人）Profile
- 用户卡（涵涵·氧气陪伴第28天）
- **我的氧气人格**横幅（氧气探索家 INTP）
- **我的氧气档案**4格：星座/五行/隐藏标签/最近状况
- **成长中心**：Lv.3氧气守护者 + 进度条(1250/2000)
- **菜单列表**：我的记录/情绪日志/聊天记录/我的成就/氧气记忆/隐私设置
