# 氧氧宝 V1.0 开发改造清单（GPT 第三轮：可直接执行版）
来源：涵姐与 GPT 讨论后，GPT 输出可直接丢给"龙虾"执行的开发清单（2026-08-23）
核心思想：不要继续堆功能，先把已有功能打磨成完整、有呼吸感的产品
目标：功能丰富 Demo → 有用户路径/陪伴感/品牌记忆点的 AI 氧气伙伴

## 总体开发原则
- 从 功能丰富的小程序Demo → 有用户路径、有陪伴感、有品牌记忆点的AI氧气伙伴
- **先不要动后端逻辑和数据结构，优先 UI/交互层重构**（最大收益来自体验提升，不是加功能）

## P0 必须完成（决定最终效果）
1. **首页重构 ⭐5**：只回答"我今天状态怎么样？氧氧希望我做什么？"
   - 第一屏（禁滚动）：氧氧问候(早上好xxx+陪伴第X天) → 今日氧气状态(氧气球82+稳定恢复中) → 一个核心建议 → 一个核心按钮[开始今日氧气调节]
   - 四维指标/7日趋势/详细分析 **不放首页**，点击氧气球 → 弹出底部卡片(今日氧气分析: 情绪能量/恢复指数/活力指数/含氧感 + 近7天趋势)
2. **底部导航优化 ⭐4**：五栏结构不改，重设计 TabBar 图标（品牌语言）：
   - 首页=氧气泡 / 氧氧=氧氧头像 / 探索=氧气实验瓶 / 充氧宝=设备+气泡 / 我的=成长树
   - 透明PNG / 81×81 / 未选中灰色 / 选中轻微放大
3. **氧氧聊天页改造 ⭐5**：AI客服 → AI陪伴伙伴
   - 顶部："氧氧助手"→"氧氧陪伴中💚陪伴第XX天"
   - 加氧氧记忆卡（你的氧气人格/最近状态/最近关注）
   - 输入前加快捷状态：😊今天不错/😐有点普通/😔有点累/😣压力大
   - 目标：用户进聊天不是为了"问问题"而是"找氧氧聊聊"
4. **我的页面改造 ⭐4**：普通个人中心 → "氧气档案馆"
   - 顶部：用户名/氧系人格/等级LvX/陪伴天数
   - 保留：氧气报告/成长记录/情绪日志；隐藏不重要设置

## P1 重要优化
5. **氧气探索页 ⭐4**：功能集合页 → "我的氧气宇宙"
   - 第一屏：你的氧气人格/氧气星球 + 4个以内入口(🧬人格探索/🧪氧气测试/🎧音疗空间/🌱成长探索)
6. **产品中心 ⭐4**：商城 → 推荐方案
   - 第一屏"根据人格推荐专属方案"→ 第二屏场景(学习/办公/旅行/睡眠) → 第三屏设备介绍

## P2 体验增强
7. **氧氧动态反馈 ⭐3**：所有成功操作加反馈（打卡完成→"氧氧收到你的照顾🌱氧气值+10 成长进度提升"）
8. **轻量动画 ⭐3**：气泡漂浮/氧氧眨眼/成长动画（不要影响加载速度）
9. **报告页重设计 ⭐3**：长报告 → 卡片式故事（氧气人格/优势/建议分页）

## 开发顺序建议（分批）
- 第一阶段：✅首页 + ✅TabBar + ✅氧氧聊天（决定第一印象）
- 第二阶段：我的页面 + 探索页 + 产品中心
- 第三阶段：动效 + 细节优化 + 全流程测试

## 最终测试清单
- 新用户流程：打开→知道氧氧是谁？→愿意测试？→生成身份？→知道下一步？
- 老用户流程：打开→马上看到今日状态？→完成一个动作？→获得反馈？
- 视觉检查每页：一屏能否讲清楚？有没有3个以上主要按钮？信息堆积？需隐藏到二级？用户知道下一步？

## 给龙虾的一句话

## 执行细节补充
### 首页深化
- 方向（生命球+今日行动+成长卡）✔ 但**不要再增加卡片**
- 目标不是"展示更多"而是"**降低认知成本**"

- **不要出现**：趋势图 / 四维数据 / 多个建议卡
- 氧气球点击 → Bottom Sheet：今日氧气详情(氧气指数82 + 四维：情绪/恢复/活力/含氧感 + 近7日趋势 + 氧氧建议)

### 氧氧聊天（比首页还重要——"AI在哪里"）
