## 录屏主链路（照着念+点）

### 第1步 · 进入（约10秒）
- 打开小程序，进入首页（陪伴 tab）
- 口播："这是氧氧宝，一个用趣味情绪检测+氧系人格+贴心陪伴，帮用户照顾当下情绪的小程序。"

### 第2步 · 状态检测（约30秒）
- 点击 IP 形象 → 打开「今日充氧手账」抽屉
- 选择一个氧状态（如：疲惫/低氧提醒）
- 输入一句话（如："今天加班到很晚，好累"）
- 可选：拍一张"氧气瞬间"照片
- 点击提交打卡
- 口播："我刚刚进行了情绪检测，选择了今天的氧状态并记录打卡。系统基于规则引擎+关键词分析出情绪，并给出状态判断。"

### 第3步 · 档案（约25秒）
- 进入「我的」或「氧气档案」页
- 展示：人格类型（氧系MBTI，如"轻氧治愈者"）+ 氧状态档案 + 历史记录
- 口播："这里是我的氧气档案，包含我的氧系人格、当前氧状态和打卡历史。"

### 第4步 · 方案（约25秒）
- 从档案/方案入口，查看根据我当前状态生成的健康建议/产品推荐
- 展示：场景（高原/运动/脑疲劳/银发）对应方案 + 充氧宝产品推荐
- 口播："系统根据我的状态和场景，给出了对应的健康建议和充氧宝产品推荐。"

### 第5步 · 打卡/陪伴（约30秒）
- 回到首页，展示成长值/成就/连续天数更新
- 或进入「陪伴/聊天」页，发一句"我最近好焦虑怎么办"
- 展示陪伴回复 + 情绪变化
- 口播："打卡后，我的成长值、成就和连续天数更新了。我还可以和氧氧宝聊聊天，获得情绪陪伴。"

### 结束（约10秒）
- 回到首页展示完整状态
- 口播："以上就是氧氧宝的主流程：检测 → 档案 → 方案 → 打卡 → 陪伴的完整闭环。"
