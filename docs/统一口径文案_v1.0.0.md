## 一、项目身份（统一用这套）
- **项目名：** 氧氧宝（充氧宝·氧系MBTI情绪陪伴小程序）
- **一句话价值主张：** 用趣味情绪检测 + 氧系MBTI人格 + 贴心陪伴，帮用户"看见、理解、照顾好当下的情绪状态"
- **技术形态：** 微信原生小程序（24 页面）+ Node.js 零依赖后端 + 原生 Canvas 数据可视化
- **当前版本：** v1.0.0（Git tag `v1.0.0`，commit `f9fbf39a097c5ebe8c0ae52a2517d888b1ee0ce6`，SHA-256 见《版本封存说明》）
- **成熟度定位：** V2 原型/Demo（可运行完整业务闭环），非"真实场景规模化落地"

## 三、能力分类标注（平台要求：真实 / 规则回退 / Mock / 规划中）

### ✅ 已实现 · 真实
- 用户注册/登录/画像/偏好（JSON 持久化）
- 情绪检测（文字/打卡 → 情绪分析，**规则引擎**）

- 成长系统 / 成就系统 / 情绪日志 / 数据可视化（原生 Canvas）
- 产品中心 / 健康场景库 / 呼吸练习 / 声疗 / 灵魂伴侣 等 24 页完整 Mock 业务闭环
