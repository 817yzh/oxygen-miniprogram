## 一、产品定位

**一句话：** "氧氧宝"是一款以**情绪健康AI**为核心的陪伴型小程序，依托充氧宝硬件，把"情绪检测 → 趣味解读 → 健康建议 → 产品推荐"串成完整闭环——让用户不仅能**发现**自己的情绪状态，还能**获得**针对性的充氧宝解决方案。

**它解决什么问题：**
- 用户想补氧，但不知道该在什么场景用、怎么选产品
- 情绪问题容易被忽视，缺乏一个"既懂我又懂产品"的贴心入口
- 充氧宝硬件缺少一个能与用户建立情感连接、持续陪伴的数字化触点

---

## 二、核心业务闭环

```
┌─────────┐   ┌─────────┐   ┌─────────┐   ┌─────────┐
│ 情绪检测 │ → │ 趣味解读 │ → │ 健康建议 │ → │ 产品推荐 │
└─────────┘   └─────────┘   └─────────┘   └─────────┘
   识别状态        看懂自己        专业建议        匹配产品
```

这四步是整条产品线的灵魂，所有功能模块都围绕它展开。

## 三、功能模块全景

### 1️⃣ 首页（home）—— 用户第一站

| 功能点 | 说明 |
|--------|------|
| 动态智能问候 | 根据时段（早/午/晚/夜）推送不同问候 + 随机暖心语 |
| 今日状态卡 | 展示当天情绪识别结果、能量值、关键词 |
| 今日关键词卡片 | 每天一次的情绪关键词提醒 + 对应暖心建议，可关闭 |
| 四大场景入口 | 高原旅行🏔️ / 脑疲劳🧠 / 运动恢复🏃 / 银发陪伴💚，含人群标签 |
| 品牌宣传视频 | 首次进入自动播放（线上地址加载） |
| IP形象互动 | "氧氧"吉祥物陪伴感，点击有暖心反馈 |

### 2️⃣ 情绪打卡（checkin）—— 检测入口

- 用户主动打卡，提交当前情绪状态
- 触发情绪识别引擎，给出情绪标签与能量值
- **是"情绪检测"环节的落地页**

### 3️⃣ AI情绪陪伴（chat）—— 数字人对话

- 关键词智能回复引擎，模拟"氧氧"陪伴用户聊天
- **智能场景识别：** 用户提到"高反/加班/肌肉酸/爸妈"等词，自动匹配对应场景
- **智能产品问答：** 用户问"多少钱/什么原理/能上飞机吗"，氧氧能回答充氧宝产品真实参数
- **产品价值点：** 它既是一个情绪陪伴者，又是一个"产品客服/导购"，完成软性产品种草

### 4️⃣ 氧系MBTI测试（mbti）—— 趣味个性化

四步流程：入口 → 答题 → 加载动画 → 结果
- **6种氧系人格：** 氧气探险家 / 深氧治愈者 / 轻氧治愈者 / 活力氧人 / 慢氧生活家 / 高氧敏感体
- **产品意义：** 用趣味测试增强用户粘性，生成个性化标签，为后续精准推荐打基础

### 5️⃣ 情绪报告（report）—— 数据可视化

- 情绪雷达图（多维分析）
- 周期情绪趋势
- 基于结果给场景化健康建议

### 6️⃣ 成长体系（growth）

- 用户等级成长、成就体系
- 趋势图展示成长轨迹 → 提升长期留存

### 7️⃣ 氧值档案（oxygen-profile）

- 氧系人格 / 能量指数档案
- 让用户"认识自己的氧能量状态"

### 8️⃣ 个人中心（profile）

- 基本信息、个性化设置

### 9️⃣ 情绪日志（emotion-log）

- 历史情绪记录回看 → 沉淀用户情感数据

### 🔟 场景方案详情（scene-detail）—— 核心推荐页

**四大场景 × 充氧宝产品精准匹配：**

| 场景 | 匹配产品 | 配套嗅吸配方 | 核心卖点 |
|------|---------|-------------|---------|
| 🏔️ **高原旅行** | 充氧宝·便携款 | 高原安神配方（薄荷+尤加利） | 快速提升血氧，缓解高反，别硬扛 |
| 🧠 **脑疲劳** | 充氧宝·桌面款 + 提神嗅吸 | 提神醒脑配方（迷迭香+薄荷+柠檬） | 比喝咖啡管用，还不影响睡眠 |
| 🏃 **运动恢复** | 充氧宝·运动款 + 恢复嗅吸 | 运动恢复配方（尤加利+薰衣草+柠檬） | 加速乳酸清除，第二天不酸痛 |
| 💚 **银发陪伴** | 充氧宝·银发款 + 安神嗅吸 | 安神助眠配方（薰衣草+洋甘菊+檀香） | 比说一百句"多保重"都实在 |

➡️ **这就是"产品推荐"环节的落地页**，也是整个小程序商业变现的核心。

## 四、产品支持体系（Work Air 充氧宝）

小程序内嵌了充氧宝完整产品知识库：

**产品型号：**
- 零售款：WA-X / WA-01 / WA-S（时尚/研发中）
- 租赁款：WA-R（共享租赁，按需使用）
- 专业款：WA-Y（研发中）

**核心优点（数字人可解答）：**
- 🔬 国家发明专利永磁体氧气富集技术（无需耗材）
- ⚖️ 仅 320~380 克，可带上飞机高铁
- 🔋 满电 3.5 小时 ≈ 21 瓶 1L 氧气瓶，可用充电宝充电
- 🏆 2024年中国优秀团体标准认证；2025年春晚拉萨分会场指定便携富氧机
- ✅ 第三方实测背书：武警西藏总队医院、布达拉宫高原测试、稻城亚丁测试等

## 五、四大应用场景（一句话总结）

> **高原**——缺氧不硬扛，随身补氧更安心
> **运动**——练完吸一吸，恢复快一倍
> **脑疲劳**——补脑供氧，久坐也高效
> **银发**——日常补氧做保健，安神陪伴给父母
